# HireHub

A modern Flutter job portal app showcasing advanced UI, sorting, filtering, and seamless URL launching.

## Overview

HireHub fetches job listings from the **ArbeitNow** API, presents them with beautiful cards, allows users to search, filter by category, sort results, bookmark favorite jobs, and view detailed job information.

## Features
- Splash screen with animated logo and tagline.
- Infinite scrolling with pull‑to‑refresh.
- Search bar and category chips for quick filtering.
- Sorting dropdown (Newest, Title (A‑Z), Company (A‑Z)).
- Tag chips displayed on the job detail page.
- Bookmarking with visual feedback.
- Accessible **Apply Now** button that launches the job's source URL via `url_launcher`.
- Dark‑mode friendly design with custom color palette.
